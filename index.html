Tambah Data SHP (ZIP)

Upload SHP dalam bentuk .zip (wajib: shp+shx+dbf; ideal: prj). Akan dimuat sebagai GeoJSON.

Label otomatis mencoba atribut: NAME/Name/name/NAMA/nama. Jika file ZIP di server memiliki spasi, gunakan %20 pada URL atau rename file tanpa spasi.
